# Mennatullah Abdelnasser — Portfolio

Static portfolio website (HTML, CSS, JavaScript only).

- `index.html` is the whole site.
- `images/` holds all project images, one folder per project.
- `videos/` holds project videos.

To publish with Netlify: drag the unzipped folder onto Netlify Drop or the Deploys page.
To publish with GitHub Pages: name the repository `username.github.io`, upload these files, then Settings > Pages > Deploy from a branch > main.
